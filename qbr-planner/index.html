Setup Firebase Sync

Your app currently uses localStorage only. To sync between users, set up Firebase:

  1. Go to console.firebase.google.com
  2. Create a new project (or use existing)
  3. Click "Add app" → Web app and copy the config
  4. Enable Firestore Database (test mode is fine)
  5. Edit qbr-planner/index.html and replace the FIREBASE_CONFIG placeholder values
  6. Commit and push — GitHub Pages will auto-deploy

Suggested Firestore Rules

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /qbrs/{qbrId} {
      allow read, write: if true;
      match /{collection}/{docId} {
        allow read, write: if true;
      }
    }
  }
}
